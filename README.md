# Три острова Python

Игра-тренажёр по первым трём юнитам курса **Programming in Python I**:

| Остров | Юнит | Темы |
|---|---|---|
| 🏝️ Остров Основ | Unit 1 | комментарии, переменные, типы, математика, строки, f-строки, преобразования, `input()` |
| 🌋 Остров Циклов | Unit 2 | сравнения и логика, `if/elif/else`, `while`, `for`/`range`, `break/continue/else`, вложенные циклы |
| 🏯 Остров Структур | Unit 3 | `list`, `tuple`, `range`, `set`, `dict`, `is` и `==`, копии, срезы, генераторы списков, распаковка, `zip/sum/min/max/all/any` |

## Режимы

- **Что выведет?** — выполняешь код в голове и выбираешь вывод (или тип ошибки).
- **Какой тип?** — что вернёт `type(...)`.
- **Тир срезов** — подбираешь `start:stop:step`, ячейки списка подсвечиваются вживую.
- **Собери программу** — расставляешь строки кода и отступы.
- **Задачи** — пишешь настоящие программы с `input()`. Их проверяют скрытые тесты, как в автопроверке курса. Python 3.12 (Pyodide) работает прямо в браузере.
- **Боссы** с тремя жизнями, **пробный экзамен**, **работа над ошибками** (интервальное повторение) и **песочница**.

Перед каждым уровнем показывается короткая шпаргалка по теме. Прогресс, опыт и ранги хранятся в браузере.

## Запуск

Сборка не нужна. Есть два способа:

1. **GitHub Pages.** Settings → Pages → Deploy from branch → выбрать ветку и папку `/ (root)`.
2. **Локально.** Запустить `python3 -m http.server` в папке проекта и открыть http://localhost:8000.

Для задач на код нужен интернет: Pyodide загружается с CDN при первом использовании.

## Как устроен контент

Все вопросы лежат в `tools/content/unit*.py`. Сборщик `tools/build.py` **выполняет каждый фрагмент настоящим Python** и записывает правильные ответы в `js/data.js`. Ответы не набираются вручную, поэтому в них не может быть опечаток. Если вывод зависит от случайного хеширования, сборщик это обнаружит и сообщит об ошибке.

```bash
python3 tools/build.py      # пересобрать js/data.js после правки вопросов
python3 tools/dump.py u2    # посмотреть ответы и объяснения для проверки
```
